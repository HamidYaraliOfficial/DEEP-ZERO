# DEEP ZERO — GDD

## Core Loop
Prepare → Dive → Operate → Detect → Investigate → Repair → Decide → Return/Continue → Save.

## Simulation pillars
Pressure, darkness, resource scarcity, system failure, sonar uncertainty, crew behavior, dynamic anomalies and persistent consequences.

## World regions
Trenches, thermal vents, canyons, caves, wreck zones, abandoned research stations, volcanic regions, ice fields, deep plains and unknown sectors.

## Horror
Context-driven pacing uses audio, silence, lighting, vibration, signal anomalies and sparse visual events; repeated jump scares are intentionally suppressed.
